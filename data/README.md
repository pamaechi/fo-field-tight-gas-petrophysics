# Input data (not distributed)

The well, core, pressure and laboratory data used in this workflow belong to the
Petroleum Agency SA (PASA) and are used under the permission granted to the
Department of Earth Science, University of the Western Cape. They are **not**
included in this repository. Researchers can request the data from PASA.

Expected layout once the data are obtained:

| Path | Content | Source |
|---|---|---|
| `data/raw/<WELL>/Raw_logs/` | LIS, DLIS and LAS field tapes for F-O1, F-O2, F-O3, F-O4, F-O6, F-O8, F-R1, F-S1 | PASA well data |
| `data/raw/<WELL>/Other/` | Routine and special core analysis reports (scanned PDF) | SOEKOR, Corex, TerraTek, Schlumberger reports |
| `data/core_data_raw_unshifted.csv` | Core plugs digitised from the reports (`petrotools/core_ocr_parse.py`) | generated |
| `data/xrd_F-O6.csv` | Quantitative XRD, F-O6 (TerraTek report TR09-402725) | transcribed |
| `data/scal/porous_plate_F-O6.json`, `data/scal/porous_plate_F-O2.json` | Porous-plate capillary pressure (format described in `scripts/composite_build/pc_build.py`) | transcribed |
| `data/petrography/*.csv` | Thin-section and modal data from the SOEKOR and TerraTek petrography reports | transcribed |

All intermediate composites (`F-O_composites_v2` to `v7`) are regenerated by the
scripts and notebooks and are written to `outputs/`.
